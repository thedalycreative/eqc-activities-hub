② What’s in a great README

      
A README.md is your project’s front door: the first thing anyone sees on GitHub. The .md means Markdown, a simple way to format text. Each card below is one part of a README, with a tiny Markdown example. “See it ↗” jumps to that exact part of our Apple clone README, so it works as an annotated example too.
