Layout

Component Description Used On Documentation
Containers Wraps content with a max-width at each breakpoint. container vs container-fluid. All Pages Docs ›

Columns Advanced column features: offsets, ordering, alignment, nesting. Mac Docs ›
Gutters Spacing between grid columns. g-*, gx-*, gy-*. Home Docs ›
Breakpoints Responsive design breakpoints: xs(<576), sm(576), md(768), lg(992), xl(1200), xxl(1400). All Pages Docs ›

Components

Component Description Used On Documentation

Alerts Contextual feedback messages. 8 colour variants, dismissible, with icons. Support, Home Docs ›
Badges Small count/label indicators. Inline, in buttons, pill-shaped. iPhone Docs ›
Breadcrumbs Navigation trail. Custom separator via --bs-breadcrumb-divider. iPhone, Support Docs ›
Buttons All variants: filled, outline, sizes, disabled, with badges. iPhone, All Pages Docs ›
Button Groups Grouped buttons, split dropdowns, toggle groups. Store Docs ›
Cards Flexible content containers. Image top/bottom/overlay, header/footer, horizontal layout. Home, Watch, iPad Docs ›
Carousel Image slideshow with indicators, captions, and prev/next controls. Home Docs ›
Close Button Styled X button for dismissing modals, alerts, toasts, offcanvas. iPhone, Store Docs ›
Collapse Toggle visibility of content. Used in navbar, accordion, and standalone. iPad, Home (navbar) Docs ›
Dropdowns Toggle menus. Headers, dividers, directions (down, up, start, end), split buttons. Store Docs ›
List Groups Styled lists with badges, active/disabled states, colours, numbered, horizontal. Watch, Home Docs ›
Modals Dialog popup windows. Standard, large, centered, scrollable. Header/body/footer. Store Docs ›
Navbar Responsive navigation. Brand, links, toggler, collapse, sticky positioning. All Pages Docs ›
Nav Tabs & Pills Tabbed navigation. Tabs (underlined) and pills (filled). Tab content panes. iPad Docs ›
Offcanvas Slide-out sidebar panels. Directions: start, end, top, bottom. Mac Docs ›
Pagination Page navigation. Active, disabled, sizes (sm/lg). Store Docs ›
Placeholders Skeleton loading states. Glow and wave animations. Watch Docs ›
Popovers Click-triggered info popups with title and content. Mac Docs ›
Progress Bars Visual progress indicators. Striped, animated, stacked/segmented, coloured. iPad Docs ›
Scrollspy Auto-highlight nav links based on scroll position. This Page Docs ›
Spinners Loading indicators. Border (rotating) and grow (pulsing). In buttons. Watch Docs ›
Toasts Pop-up notification messages. Positioned, coloured, auto-hide, JS triggered. Watch Docs ›
Tooltips Hover-triggered info popups. Placement: top, right, bottom, left. Mac Docs ›

JavaScript Behaviours

Note: Most Bootstrap JS components work via data-bs-* attributes (no custom JavaScript needed). Tooltips and Popovers are the exception - they must be initialized manually for performance reasons.
Feature Description Used On Documentation
data-bs-toggle Core attribute. Values: collapse, tab, pill, modal, dropdown, offcanvas, tooltip, popover, toast. All Pages Docs ›
data-bs-dismiss Close/dismiss: alert, modal, offcanvas, toast. Used on close buttons. Multiple Pages Docs ›
Tooltip Init Must be manually initialized: new bootstrap.Tooltip(el). Mac Docs ›
Popover Init Must be manually initialized: new bootstrap.Popover(el). Mac Docs ›
Form Validation Custom validation using novalidate + was-validated class via JS. Store Docs ›
Toast JS API Show/hide toasts programmatically: bootstrap.Toast.getOrCreateInstance(el).show(). Watch Docs ›
